## Run it

```sh
python3 main.py
```

The program copies the image the repository holds (`entry.png`,
1024×1024) to `/output/entry.png` (`MAKEFUN_OUTPUT_DIR` overrides the
output directory outside the grader). No network, no randomness: two runs
write identical bytes.
